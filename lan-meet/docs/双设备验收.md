# 双设备验收

开始前：两台设备均连接同一受控局域网，队长机 IP 已固定，第二台设备已导入本届 `meet.crt`。

1. 队长机执行 `scripts/Test-LanMeet.ps1`，确认 compose 输出只有 LAN HTTPS 与 LAN UDP 媒体端口。
2. 第二台设备访问 `https://<队长机 LAN IP>:8443`，确认地址栏无证书错误。
3. 使用未来 Election 的 `GET /meet/token` 所签发令牌加入同一房间；验证双向麦克风、摄像头、屏幕共享与离会。
4. 在没有令牌、过期令牌、错误房间令牌三种情况下尝试进入，均必须被拒绝。
5. 在两台机器上抓取本地会议期间连接：音视频仅应为队长机 LAN IP 的 TCP 8443 与 UDP 10000；不得出现 TURN/STUN、JaaS、Sentry、rtcstats 或公网媒体端点。
6. 断开互联网但保持局域网后，已进入的会议媒体应持续可用；新加入是否可用取决于 MC-2 令牌是否可缓存，当前设计不承诺离线签发令牌。
7. 测试结束后执行 `scripts/Start-LanMeet.ps1 -Stop`，确认 `docker compose ps` 无残留会议容器。
