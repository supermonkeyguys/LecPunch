# 队长机启动说明

完整会议栈保存于 `C:\Docker\LecPunch-LAN-Meet`。该目录包含本届会议的 `.env`、自签证书和密钥，已限制为当前 Windows 用户、Administrators 与 SYSTEM 可访问；不要复制到桌面、群文件或 Git 仓库。

## 每次开会

1. 启动 Docker Desktop，等待其状态显示正在运行。
2. 用 PowerShell 执行：

```powershell
Set-Location 'C:\Docker\LecPunch-LAN-Meet'
.\scripts\Start-LanMeet.ps1
.\scripts\Test-LanMeet.ps1
```

3. 将会议房间名发给成员；成员通过 Election 自己取得短时令牌入会。
4. 会议期间保持队长机、Docker Desktop 和局域网连接正常。

## 结束会议

```powershell
Set-Location 'C:\Docker\LecPunch-LAN-Meet'
.\scripts\Start-LanMeet.ps1 -Stop
```

## 重要边界

- 不要编辑、分享或提交 `.env`、`certs\meet.key`、`.runtime`、`.upstream`。
- 不要把端口改成 `0.0.0.0`；会议只允许局域网 IP 的 8443/TCP 与 10000/UDP。
- 队长机 IP 变更、证书过期或更换队长时，按项目内 `docs\队长交接.md` 操作，不要直接猜改密钥。
