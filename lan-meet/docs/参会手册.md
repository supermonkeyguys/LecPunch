# LEC 局域网视频会议参会手册

这份参会包仅适用于同一团队局域网内的 LEC 视频会议。日常参会只需使用 LecPunch Election；不需要手工请求接口、复制令牌或输入会议服务器账号密码。

## 会前一次性准备

1. 确认电脑已连接团队局域网。
2. 从本参会包取得 `meet.crt`。只信任由队长发出的这张证书，不要跳过任何未知网站的证书警告。
3. 按 `Win + R`，输入 `certmgr.msc` 并回车。
4. 打开“受信任的根证书颁发机构” → “证书”。
5. 右键空白处 → “所有任务” → “导入”，选择本包的 `meet.crt`。
6. 存储位置选择“受信任的根证书颁发机构”，完成导入。
7. 重新打开 Election（若它当时已在运行）。

## 在 Election 中配置会议地址

1. 登录自己的 LecPunch 账号。
2. 点击右上角头像，进入“个人设置”。
3. 找到“局域网会议”。
4. 填入当前队长机地址：`https://192.168.5.95:8443`。
5. 点击“保存会议地址”。

地址只保存在本机，不会上传到服务器。若队长通知 IP 已变更，以队长提供的新地址为准。

## 创建或加入一场会议

1. 在左侧进入“视频会议”。
2. 输入队长通知的房间名，例如 `weekly-standup`。
3. 房间名仅能使用字母、数字、下划线和连字符；不能包含空格或中文。
4. 点击“安全入会”。
5. 第一次进入时允许摄像头与麦克风。
6. 所有人输入同一个房间名，即可进入同一场会议。

队长可在“视频会议”页面点击“复制邀请”。邀请只包含房间名和会议地址，不包含令牌；这是正常的安全设计。

## 令牌与重新入会

- Election 会自动以你的登录身份取得只对当前房间有效的短时令牌，有效期为 5 分钟。
- 不要转发带 `jwt=` 的完整会议链接。
- 页面提示令牌到期、刷新后被拒绝或要重新进入时，点击“重新取得会议令牌”。

## 常见问题

| 现象 | 处理方式 |
| --- | --- |
| “安全入会”按钮不可用 | 先在“个人设置”保存局域网会议地址。 |
| 证书错误 | 关闭 Election，确认已按上方步骤导入本包 `meet.crt`，再重新打开。 |
| 401 或无法取得令牌 | 确认已登录有效成员账号，且 LecPunch 服务可访问。 |
| 摄像头/麦克风不可用 | 在 Windows 隐私设置中允许 Election 使用摄像头和麦克风。 |
| 无法连上会议 | 确认在同一局域网，并联系队长确认会场机已启动且地址没有变更。 |

## 备用方式（仅 Election 无法使用时）

本包附带 `Join-LanMeet.ps1`。它会在 PowerShell 中安全询问你的 LecPunch 用户名和密码，取得短时令牌后用系统浏览器打开会议。正常情况下优先使用 Election；备用脚本不会保存你的密码。
