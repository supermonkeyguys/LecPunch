# 端口与防火墙规则

| 服务 | 协议 | 队长机端口 | 可访问范围 | 用途 |
| --- | --- | --- | --- | --- |
| Jitsi Web | TCP | 8443 | `LAN_ALLOWED_CIDR` | HTTPS 页面、信令、屏幕共享控制通道。 |
| Jitsi Videobridge | UDP | 10000 | `LAN_ALLOWED_CIDR` | 音视频媒体。 |
| Jicofo REST | 无主机映射 | — | 容器内部 | 管理内部组件。 |
| Prosody | 无主机映射 | — | 容器内部 | XMPP 信令。 |

规则：

- Docker compose 只能将 8443/TCP 与 10000/UDP 发布到 `LAN_BIND_IP`；禁止 `0.0.0.0`。
- Windows 防火墙规则仅启用在 **Private** 网络配置文件，远端地址限制为 `LAN_ALLOWED_CIDR`。
- 禁止路由器端口映射、UPnP、DDNS、Cloudflare Tunnel、frp 或任何公网转发。
- 禁用 TURN、STUN、P2P、Octo、录制、直播、JaaS、rtcstats、Sentry 与 tracing。
- API 令牌请求仍会访问已有 LecPunch API；这不是音视频流。若要求完全断网会议，MC-2 的在线令牌模式不能满足，需要另立本地身份验证方案。
